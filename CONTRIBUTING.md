# Участие в Void Connect

Это ранняя разработка; крупное изменение сначала обсудите в Issue.

1. Найдите задачу или создайте предложение с пользовательским сценарием.
2. Сделайте отдельную ветку с небольшим законченным изменением.
3. Используйте Flutter 3.47.5 и выполните `flutter pub get`.
4. Выполните `dart format lib test integration_test`, `flutter analyze` и `flutter test`.
5. Проверьте RU/EN, узкий и широкий экран.
6. В Pull Request опишите результат и проверки; обновите документацию.

Для платформенного кода укажите проверки Windows и Android. Тестируйте поведение, не копии реализации. Добавляйте строки сразу для RU и EN.

Запускайте `integration_test/platform_smoke_test.dart` на целевой платформе; условия сохранности данных и команды приведены в README. Android-прогон использует тестовый APK с последующим удалением пакета, поэтому требует отдельного тестового устройства/профиля или предварительного сохранения данных приложения.

Не добавляйте токены, файлы подписания, пароли и личные данные. Используйте минимальные примеры и обезличенные логи.

Лицензия ещё не выбрана. До её определения согласуйте условия существенных внешних вкладов с владельцем проекта.
