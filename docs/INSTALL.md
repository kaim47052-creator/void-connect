# Установка Void Connect

Предварительная версия для тестирования Windows и Android. APK скачивается напрямую, без Google Play. В GitHub Releases выбирайте опубликованный preview и проверяйте его версию; черновики доступны только владельцу репозитория.

## Windows x64

1. Скачайте `void-connect-<version>-windows-x64.zip` из выпуска.
2. Распакуйте **весь** ZIP в выбранную папку.
3. Откройте `VoidConnect.exe` из распакованной папки. DLL и каталог `data` должны оставаться рядом с EXE.

Оригинальные библиотеки Visual C++ включены в подготовленный ZIP. EXE пока без подписи Authenticode; происхождение пакета можно сверить с репозиторием и SHA256 выпуска. Не отключайте защиту Windows для установки. Проверенная система — Windows 11 x64.

Язык и библиотека сохраняются в `%APPDATA%\VoidConnect`. Для обновления закройте приложение и распакуйте новый ZIP в отдельную папку; данные сохраняются независимо от папки EXE. Перед переходом при необходимости скопируйте `app-library.txt` и `language.txt` в личную резервную папку.

## Android

1. Скачайте `void-connect-<version>-android.apk` из выпуска. Архивировать или извлекать APK не нужно.
2. Откройте APK на телефоне. Если Android запросит право установки, разрешите установку именно приложению, которым открываете этот файл. После установки право можно отключить.
3. Откройте «Void Connect», добавьте нужные приложения в библиотеку и выберите RU/EN.

Манифест задаёт Android 7.0 / API 24 и выше. Текущие проверки устройства выполнялись на Android 17 / API 37; остальные версии требуют отдельной проверки совместимости.

### Переход с прежних тестовых APK

Начиная с preview.4 подготовленный release APK имеет отдельную постоянную подпись. Debug APK из предыдущих выпусков и CI имеют другую подпись. Android не разрешает обычное обновление поверх APK с другим сертификатом.

**Не удаляйте прежнюю установку, если хотите сохранить её библиотеку и язык.** Текущий MVP не имеет кнопки экспорта/импорта. Через ADB разработчик может сохранить только настройки прежней debug-установки, но автоматического переноса в production APK ещё нет. Поэтому переход с установленной тестовой версии требует отдельного шага миграции; APK можно проверять на чистом тестовом устройстве.

Будущие release APK с тем же application ID `dev.voidconnect.void_connect` и тем же постоянным ключом рассчитаны на обновление с сохранением данных. Сборки `Void Connect Check` / `.releasecheck` предназначены только для проверки и не являются выпускаемым приложением.

## Проверка файлов

Выпуск включает `SHA256SUMS.txt` и `release-manifest.json`. Например, в PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\void-connect-<version>-android.apk
```

Сравните результат с соответствующей строкой `SHA256SUMS.txt`. Контрольная сумма обнаруживает изменение файла; это не механизм автообновления и не заменяет проверку источника.

## Возможности preview

Доступны библиотека приложений, поиск/запуск, RU/EN и адаптивный интерфейс. Синхронизация, привязка телефона, плагины, автообновления и новые QR-сценарии пока в плане. Проверки и ограничения: `docs/testing/` в репозитории.
