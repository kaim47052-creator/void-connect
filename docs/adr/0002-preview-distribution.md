# ADR 0002: Прямое распространение предварительных выпусков

- **Статус:** принято для подготовки v0.1
- **Дата:** 2026-10-07
- **Область:** выпуск, подписи и идентификаторы

## Контекст

Владелец выбрал MIT для исходного кода и прямое распространение Android без Google Play. В старых preview используется debug-подпись. Требуются постоянные файлы выпуска, воспроизводимая упаковка и сохранность текущей тестовой установки.

## Решение

- GitHub Releases хранит версионированные предварительные APK и Windows x64 ZIP с документацией и SHA256. Новый выпуск сначала готовится как draft.
- Android ID v0.1 сохраняется `dev.voidconnect.void_connect`; пользовательское название Void Connect. Windows EXE `VoidConnect.exe`, данные остаются в `%APPDATA%/VoidConnect`.
- Production APK подписывается отдельным локальным ключом; сертификат фиксируется в публичной документации. Ключ и пароль не передаются в CI. Release без конфигурации подписи запрещён.
- Для проверки рядом с debug-установкой допустим временный release APK с суффиксом `.releasecheck`; он не входит в выпуск. Упаковка проверяет ID, версию, подпись и отсутствие debug-флага.
- Windows ZIP содержит Flutter bundle и оригинальные необходимые VC runtime DLL. Authenticode/MSIX пока не вводятся.
- MIT применяется к коду проекта; сторонние лицензии и уведомления сохраняются.
- QR для скачивания и привязки, автообновления и откат остаются будущими задачами. Архитектура приложения не меняется.

## Последствия

Debug → production требует миграции: Android отклоняет APK с другой подписью. Существующую установку не удаляем при проверке release. Публичный выпуск и переход владельца требуют сохранения ключа и данных; общего экспорта/импорта в MVP пока нет. Проверка подписи и суммы файлов не реализует автоматическое обновление.
