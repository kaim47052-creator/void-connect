# Void Connect v0.1.0-preview.4

Предварительный выпуск Windows + Android, версия приложения 0.1.0+4. Библиотека приложений, поиск и запуск, RU/EN, адаптивный интерфейс и уменьшение движения. Синхронизация, плагины, обновления и новые QR-сценарии пока в плане.

## Файлы

- `void-connect-0.1.0-preview.4-android.apk` — release APK, отдельная постоянная подпись, прямое скачивание без Google Play.
- `void-connect-0.1.0-preview.4-windows-x64.zip` — распакуйте целиком и запустите `VoidConnect.exe`. Flutter data, DLL и оригинальные VC runtime включены. EXE пока без Authenticode.
- `INSTALL.md`, `CHANGELOG.md`, `LICENSE`, `THIRD_PARTY_NOTICES.md`, `release-manifest.json`, `SHA256SUMS.txt` — инструкции, изменения, лицензии и проверка файлов.

Код Void Connect — MIT. Сторонние компоненты сохраняют свои условия.

## Перед установкой на телефон

Прежние debug APK имеют другую подпись. Android не разрешит обычное обновление поверх них. **Не удаляйте установленную тестовую версию без сохранения её библиотеки и языка.** Универсальный экспорт/импорт ещё не реализован; переход с debug требует отдельного шага миграции. Будущие production-обновления должны использовать тот же постоянный ключ и ID.

## Проверки

- 15 widget tests, анализ и форматирование прошли.
- 6 Windows native tests прошли; `VoidConnect.exe` собран как release, версия 0.1.0+4.
- Подпись production APK проверена `apksigner`, ID/версия проверены по манифесту.
- Подписанный APK с тем же кодом и проверочным суффиксом `.releasecheck` установлен на реальном Android 17: добавление/запуск/удаление Chrome, RU → EN и сохранение EN после перезапуска подтверждены. Проверочная установка удалена; исходная установка пользователя сохранена.
- Упаковка отклоняет проверочный APK; release без подписи запрещён; генератор отказывается заменять существующий ключ.
- Windows ZIP проверен: нужный EXE, runtime и лицензии на месте, старый EXE не включён.

Остаются ручные проверки физической клавиатуры, экранных дикторов и переключения системных анимаций Windows. Точный production APK с основным ID не устанавливался поверх debug-версии; проверочная установка использовала отдельный ID. Отдельный визуальный запуск новой Windows release здесь не подтверждён.
