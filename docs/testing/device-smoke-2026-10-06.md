## Не подтверждено инструментом

### Ctrl+F

Временный журнал обработчика клавиш показал последовательность:

1. Control down: ctrl=true.
2. Control up: ctrl=false.
3. F down: logicalF=true, physicalF=false, ctrl=false.
4. F up: logicalF=true, physicalF=false, ctrl=true.

Таким образом, инструмент не передаёт обычное одновременное сочетание Ctrl+F и физический код F. Отсутствие перехода к поиску через этот инструмент не является проверкой настоящей клавиатуры. Автоматический тест настоящего формата KeyEvent с удержанным Ctrl проходит; ручной сценарий с физической клавиатурой остаётся неподтверждённым.

### Переключение системных анимаций Windows

Открыта штатная панель Performance Options. В исходном состоянии выбран режим «Let Windows choose…», первый флажок «Animate controls and elements inside windows» включён. Панель не отреагировала на ввод инструмента; новое значение и Apply не были подтверждены. Системные изменения не применены. Подтверждено только чтение текущего значения приложением; уведомление об изменении покрыто тестом с подменённым каналом.

TalkBack/Narrator, ошибки запуска удалённых приложений и отключение анимаций Windows с настоящей клавиатуры/мыши остаются отдельными проверками. Задача #3 сохраняет эти ограничения.
