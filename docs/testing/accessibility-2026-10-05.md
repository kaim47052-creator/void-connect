# Проверка переходов и доступности

Последующая проверка на реальном Android и узком Windows-окне: [2026-10-06](device-smoke-2026-10-06.md).

Дата: 2026-10-05. Версия приложения: 0.1.0+3.

## Автоматические проверки

Flutter 3.47.5 stable; 15 widget tests проходят:

- RU/EN, сохранение языка и fallback.
- Библиотека: добавление, поиск, запуск, удаление и сообщение о недоступности.
- Ctrl+F с различающимися физической и логической клавишами, Escape для очистки поиска, Tab/Shift+Tab, Enter и возврат фокуса после закрытия диалога.
- Отключение переходов библиотеки и диалога при системном флаге Flutter.
- Нативное значение Windows и изменение настройки во время работы через подменённый канал.
- Длинные названия и текст 200%: библиотека и диалог, RU/EN, ширина 320 и 1280 логических пикселей.
- Flutter guidelines для подписей, целей нажатия Android и контраста текста на основном экране и в диалоге.

Форматирование и flutter analyze проходят. Windows release собран локально официальным SDK.

## Ручная проверка Windows

На запущенной release-сборке проверены:

- Tab переводит фокус через кнопки языка, поиск и кнопку добавления; видна фиолетовая граница.
- Shift+Tab возвращает фокус с кнопки в поиск.
- Ввод с текущей русской раскладкой фильтрует библиотеку; Escape очищает запрос и восстанавливает список.
- Enter на кнопке открывает диалог; поле поиска получает фокус.
- Escape закрывает диалог; фокус возвращается на кнопку добавления.
- UI Automation получает подписи запуска и удаления с названием приложения, а также названия языков.
- Уходящие состояния перестают присутствовать в дереве доступности после перехода.

Сохранённые пользователем записи библиотеки не удалялись.

## Границы и дальнейшая проверка

Ctrl+F не удалось подтвердить через средство ввода окна: сочетание не перевело фокус, а клавиша Cyrillic_ef не поддерживается инструментом. Автоматический тест проходит; реальное сочетание с физической клавиатуры требует проверки пользователем. Это не считается успешной ручной проверкой.

Системная настройка анимаций Windows не изменялась. Проверены сборка нативного чтения и передача значения через подменённый канал; переключение настройки на реальной ОС ещё требует проверки. TalkBack, Narrator и новый интерфейс на физическом Android в этой проверке не запускались. Проверки размеров и текста Android выполнялись как widget tests, а не на телефоне.

Тесты Flutter guidelines покрывают текущие отображённые элементы и не являются полной сертификацией доступности. Расширенная проверка устройств остаётся отдельным пунктом плана.
