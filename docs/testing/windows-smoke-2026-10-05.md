# Ручная проверка Windows

Дата: 2026-10-05 (America/Los_Angeles).
Платформа: Windows x64, локальная release-сборка.
Метод: настоящее окно приложения через Computer Use.

## Основные сценарии

На исходной сборке `60f4a32` проверены:

- запуск окна приложения;
- переключение EN → RU и сохранение RU после полного закрытия и запуска;
- добавление File Explorer в библиотеку и запуск Проводника;
- переключение RU → EN;
- сохранение EN и выбранной записи после полного закрытия и запуска;
- фильтрация списка добавления, пустой результат поиска библиотеки и восстановление записи после очистки запроса.

## Исправление Issue #8

Раньше вместо названия File Explorer выводилось «Displays the files and folders on your computer.». Причина: `IShellLinkW::GetDescription` возвращает описание ярлыка.

Исправленный адаптер получает отображаемое имя через [SHGetFileInfoW / SHGFI_DISPLAYNAME](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow), убирает суффикс `.lnk`, если он присутствует, и использует имя файла без расширения при ошибке получения имени. Системный идентификатор ярлыка не изменён.

После исправления повторно проверены:

- ранее сохранённая запись отображается как `File Explorer` без повторного добавления;
- каталог показывает `Live captions`, `Magnifier`, `Narrator`, `On-Screen Keyboard`, `Voice access` и `File Explorer` вместо длинных описаний;
- запуск Проводника из существующей записи открывает окно `Home - File Explorer`.

Форматирование, `flutter analyze`, все 7 widget tests и локальная Windows release-сборка прошли.

## Границы проверки

Удаление записи, запуск отсутствующего ярлыка, все установленные приложения, изменение размера окна и все клавиатурные сочетания пока не проверялись вручную. Widget tests отдельно покрывают удаление и сообщение о недоступном приложении через подмену платформенного канала.

У средств автоматизации возникли сбои доступности элементов и ввода текста; фильтрация проверялась обычными клавишами. Эти сбои не считаются дефектами приложения без отдельного воспроизведения.

После проверки интерфейс оставлен на EN, в библиотеке сохранена тестовая запись File Explorer. Созданное проверкой окно Проводника закрыто.
