# Изменения Void Connect

## v0.1.0-preview.4 — 2026-10-07

Предварительный выпуск; версия приложения 0.1.0+4.

- Библиотека приложений Windows/Android: добавление, поиск, запуск и удаление записей.
- RU/EN, сохранение языка и выбор языка устройства.
- Адаптивный тёмный интерфейс, крупный текст, клавиатура, подписи действий и уменьшение движения.
- Исправлено принятие пустого идентификатора в Windows.
- 15 тестов интерфейса и 6 нативных проверок; Windows-тесты включены в CI.
- Название «Void Connect» на обеих платформах; Windows EXE `VoidConnect.exe`.
- MIT для кода проекта. Android release подписывается отдельным постоянным ключом; fallback на debug-подпись удалён.
- Подготовлены APK для прямого скачивания, Windows ZIP с runtime, инструкции и контрольные суммы.

Синхронизация, привязка устройств, плагины и автообновления ещё не реализованы. Новые QR-сценарии отложены. Ручная проверка физических клавиш, экранных дикторов и системного переключателя анимаций Windows остаётся открытой.

Новая подпись несовместима с установленными debug APK. Не удаляйте текущую установку без сохранения настроек; см. [инструкцию](docs/INSTALL.md).
